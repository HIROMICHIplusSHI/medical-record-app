# 問診票仕様書（改訂版）

## 概要

iPad等のタブレットで患者様に直接入力してもらうことを想定した、ユーザーフレンドリーな問診票システム。
チェックボックス主体の直感的なUIで、入力の手間を最小限に抑える。

## 設計思想

### 1. ユーザビリティ重視
- **チェックボックス主体**: テキスト入力を最小限に
- **段階的な質問**: 該当する場合のみ詳細を表示
- **大きなタッチターゲット**: iPad操作に最適化
- **視認性の高いデザイン**: 高齢者でも見やすく

### 2. 運用フロー
```
予約受付（電話等）
  ↓
仮患者登録（カタカナ名 + 電話番号のみ）
  ↓
来院時：iPadで問診票記入
  ↓
問診票データを患者情報に反映
  ↓
カルテ作成・施術開始
```

## 問診票の構成

### セクション1: 基本情報（必須）

患者の基本情報を収集。予約時の情報を補完する。

| 項目 | 入力タイプ | 必須 | 説明 |
|------|-----------|------|------|
| 氏名（漢字） | テキスト | ✓ | フルネーム |
| フリガナ | テキスト | ✓ | カタカナ |
| 生年月日 | 日付選択 | ✓ | 年齢確認・年齢制限チェック用 |
| 性別 | ラジオボタン | ✓ | 男性 / 女性 / その他 / 回答しない |
| 電話番号 | テキスト | ✓ | ハイフン自動挿入 |
| メールアドレス | テキスト |  | 任意 |
| 郵便番号 | テキスト |  | 住所自動入力に使用 |
| 住所 | テキスト |  | 任意 |
| 緊急連絡先 | テキスト |  | 本人以外の連絡先 |

## データモデル設計

### Questionnaireモデル

```ruby
class Questionnaire < ApplicationRecord
  belongs_to :patient

  # 基本情報（患者情報と重複するが、問診票記入時点での情報として保持）
  encrypts :full_name              # 氏名（漢字）
  encrypts :full_name_kana         # フリガナ
  encrypts :birth_date             # 生年月日
  encrypts :gender                 # 性別
  encrypts :phone                  # 電話番号
  encrypts :email                  # メールアドレス
  encrypts :postal_code            # 郵便番号
  encrypts :address                # 住所
  encrypts :emergency_contact      # 緊急連絡先

  # 医療情報（JSON形式で柔軟に保存）
  encrypts :medical_conditions     # 既往歴・治療中の病気
  encrypts :allergies              # アレルギー
  encrypts :current_medications    # 服薬状況
  encrypts :past_surgeries         # 手術歴
  encrypts :pregnancy_info         # 妊娠・授乳情報

  # 施術情報
  encrypts :desired_treatments     # 希望施術
  encrypts :past_treatments        # 過去のアートメイク経験
  encrypts :skin_conditions        # 肌の状態
  encrypts :other_concerns         # その他相談事項

  validates :patient, uniqueness: true
  validates :full_name, :full_name_kana, :birth_date, :gender, :phone, presence: true
end
```

### JSON構造例

#### medical_conditions（既往歴）
```json
{
  "has_conditions": true,
  "conditions": [
    "hypertension",
    "diabetes"

  "other_condition": "慢性胃炎"

```

```json
  ],
  "drug_allergy_detail": "ペニシリン系",
```

```json
  "taking_medications": true,

    "blood_pressure",
```

```json
    "had_trouble": false,
    "trouble_detail": ""
  }
}
```

## セキュリティ要件

### 暗号化
- すべての個人情報・医療情報を暗号化
- Active Record Encryption（AES-256-GCM）
- 暗号化キーはRails credentialsで管理

### アクセス制御
- ユーザーは自分の施設の患者のみアクセス可能
- 問診票は該当患者に紐づくユーザーのみ閲覧・編集可能

### データ保持
- 問診票データは患者情報と独立して保持
- 後から問診票の内容を確認・参照可能
- カルテ作成後も問診票データは保持
