## 📋 Phase 6 実装計画

### 🎯 Phase 6の目的

**Phase 5-D/5-Eは棚上げ**し、以下の新機能を優先実装：

1. **権限管理（RBAC）**: 管理者とユーザーを分離
2. **紹介制度**: 会員登録を紹介制にして不特定多数の登録を防ぐ
3. **ホームページ作成**: アナウンス表示、ダッシュボードとの分離
4. **UI/UX改善**: ログインページ改善、Googleログイン削除
5. **利用規約整備**: 法的コンプライアンス対応
